About this archive & the display data

Different observations. Matching pixels.

Each site’s LiDAR-based DEM defines a shared 3 m reference grid. All co-registered science rasters—terrain, snow depth, vegetation and UAVSAR—use the same coordinate system, pixel centres and array shape within that site. Matching row and column indices therefore refer to the same mapped location. Coverage and acquisition dates can differ; in-situ measurements remain point records. Open the DEM’s info panel for its original download, site-specific grid and resampling equation.

Current scope: data exploration for snow-depth research. NISAR integration and snow-water-equivalent products are future work.

A preview, not the full-resolution archive.

These entrance-page terrains are sampled from the existing exported DEMs, with 2× vertical exaggeration. Colours are illustrative elevation shading. The archive grid is the finest stored common grid, not the native resolution of every instrument. The explorer terrain and this lightweight preview are sampled more coarsely; radar colour layers may be coarser still. Use the HDF5 archive for full-resolution analysis.
